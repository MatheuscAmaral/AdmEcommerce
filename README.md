# Adm E-commerce

Bem-vindo ao repositório do **Adm E-commerce**, uma aplicação desenvolvida em **Next.js** para gerenciar e administrar todos os aspectos do seu e-commerce de suplementos. Este painel oferece ferramentas para criação e gerenciamento de produtos, pedidos, formas de pagamento, gateways e muito mais.

## Descrição

O **Adm E-commerce** fornece um ambiente completo para gerenciar de forma centralizada todo o seu e-commerce. Criado com **Next.js**, o painel garante uma experiência fluida, responsiva e de alta performance para os administradores e colaboradores que precisam gerenciar o estoque, as vendas, os clientes e outros recursos essenciais do negócio.

## Tecnologias Utilizadas

- **Next.js** – Framework React para desenvolvimento de aplicações web (server-side e client-side).
- **React.js** – Biblioteca JavaScript para construção de interfaces de usuário.
- **Axios** – Biblioteca para requisições HTTP e integração com a API do e-commerce.
- **Redux / React Context** (opcional) – Gerenciamento global de estado para dados de usuários, produtos e pedidos.
- **TypeScript** (opcional) – Fornece tipagem estática para maior segurança e manutenibilidade do código.
- **CSS Modules / Styled Components / Tailwind CSS** – (dependendo da abordagem de estilização adotada).
- **Node.js & npm / yarn** – Ambiente e gerenciador de pacotes para desenvolvimento.

## Funcionalidades Principais

1. **Gerenciamento de Produtos**  
   - Criar, editar e remover produtos.  
   - Upload de imagens e gerenciamento de estoque.  
   - Organização de produtos por categorias e tags.

2. **Gerenciamento de Pedidos**  
   - Visualizar a lista de pedidos em tempo real.  
   - Atualizar status de pedidos (processando, enviado, entregue, etc.).  
   - Exibir detalhes do pedido, produtos, valores e dados do cliente.

3. **Formas de Pagamento e Gateways**  
   - Configurar e gerenciar integrações com gateways de pagamento (Asaas, PayPal, PagSeguro, etc.).  
   - Ativar ou desativar métodos de pagamento e definir taxas ou descontos.

4. **Gerenciamento de Usuários**  
   - Controle de permissões e níveis de acesso (administradores, operadores, etc.).  
   - Visualização de cadastro de clientes (nome, email, histórico de compras, etc.).

5. **Layout Responsivo**  
   - Interface adaptada para diferentes dispositivos e tamanhos de tela.  
   - Garantia de produtividade independente do dispositivo utilizado.
